# Mini Compliance Tracker

## 🚀 Overview

This is a simple full-stack web application built to manage compliance tasks for multiple clients.
Users can view clients, track their tasks, update statuses, and identify overdue tasks easily.

---

## ✨ Features

### ✅ Core Features

* View list of clients
* Select a client to view tasks
* Add new compliance tasks
* Update task status (Pending → Completed)
* Filter tasks by status and category
* Highlight overdue tasks clearly

### ⭐ Bonus Features

* Search tasks by title
* Sort tasks by due date
* Summary dashboard (Total, Pending, Completed, Overdue)
* Seed data for quick setup
* Docker setup for backend

---

## 🌐 API Endpoints

* GET `/api/clients` → Get all clients
* GET `/api/tasks/:clientId` → Get tasks for a client
* POST `/api/tasks` → Create new task
* PUT `/api/tasks/:id` → Update task status

---

## 🧪 How to Use

1. Open the app
2. Select a client
3. View tasks
4. Add a new task
5. Update task status
6. Use filters/search/sorting
7. Check overdue tasks

---

## ⚖️ Tradeoffs

* No authentication system implemented
* Minimal UI design (focused on functionality)
* No pagination for large datasets

---

## 📌 Assumptions

* Single-user system
* Clients are pre-seeded in database
* Task statuses are limited to "Pending" and "Completed"
